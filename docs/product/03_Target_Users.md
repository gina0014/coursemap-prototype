# 03 · 目标用户（Target Users）

## 第一阶段核心用户

**18–30 岁大学生及青年学习者**，正在为学业、科研或求职补充数字技能与科研技能。

### 用户画像（示意，非真实访谈数据）

1. **零基础转向者**：文科背景的大学生，想学会 Python / 数据分析，
   预算敏感（<¥200），每周 3–6 小时。
2. **科研新人**：需要统计基础 / R 语言 / 文献检索 / 单细胞分析入门的研究生，
   时间紧，需要先修关系指引。
3. **求职冲刺者**：毕业前 1 年，想快速补齐 AI 工具使用 / 学术英语写作，
   在意证书与口碑证据。

### 共同痛点

- 平台太多，先找平台再翻课程的路径效率低。
- 不知道自己的基础适合哪档难度的资源。
- 付费前无法判断课程质量与负荷是否属实。

## 第一阶段领域聚焦

大学生数字技能与科研技能。首批 Subject：

- 编程
- 数据分析
- 人工智能
- 科研方法
- 学术英语

## 明确不做（第一阶段）

- K12 全学科 / 儿童教育 / 老年教育
- 所有职业资格
- 所有全球教育领域

范围扩张的原则：先把「目标 → 资源 → 比较 → 路径 → 决策」链路在一个窄领域
验证出真实价值，再横向扩展。
