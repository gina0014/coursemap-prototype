# 12 · 商业模式（Business Model）

> 本文档记录**规划**，不代表任何已上线的收费功能。v0.1 无支付、无账号、无收费。

| 模块 | 内容 | 状态 |
| --- | --- | --- |
| A. Consumer Free | 搜索 / 对比 / 学习路径 / 基础收藏 | Implemented（原型内） |
| B. CourseMap Pro | AI 学习顾问完整版 / 个性化路径 / 进度跟踪 / 技能差距分析 / 长期学习档案 | Planned |
| C. Provider Pro | Provider Claim / 资源更新 / Analytics / 需求趋势 / 对比洞察 | Planned |
| D. B2B Education Intelligence | 高校 / 企业培训 / 教育机构的聚合洞察 | Hypothesis |
| E. Affiliate / Transaction | 合法课程 Referral Commission | Hypothesis |
| F. Sponsored Resource | 赞助位，必须明确标注 Sponsored；**付费 ≠ 自然排序** | Planned（红线先行） |
| G. Data Intelligence | 匿名聚合的学习需求趋势 | Hypothesis |

## 关键红线

1. Sponsored 资源必须带显著标识，且商业合作**不得影响**自然检索与对比排序。
2. Affiliate 涉嫌利益冲突时，对比页必须披露。
3. 数据智能只做匿名聚合，不做个体画像贩卖。

详见 `docs/business/Business_Plan.md`。
